# Linkt Cookbook

Code examples and recipes for building with the [Linkt Python SDK](https://github.com/linkt-ai/linkt-python-sdk).

## Overview

This repository contains practical examples for GTM engineers building custom research agent workflows with the Linkt API.

## Prerequisites

- Python 3.9+
- A Linkt API key

## Installation

```bash
pip install linkt-sdk
```

## Quick Reference

```python
from linkt import Linkt

client = Linkt(api_key="your-api-key")
# Or set LINKT_API_KEY environment variable
```
